# 使用说明

按角色说明系统怎么用。左侧菜单会按当前账号的角色自动裁剪，看不到的菜单就是该角色没有权限的模块。

涉及的演示账号见 [README.md](README.md#5-登录)。

---

## 一、学生

### 1. 选题

1. 进入 **课题管理**，浏览状态为「开放申报」的课题
2. 点击 **申报**，填写申请说明（选填）后提交
3. 到 **选题管理** 查看申请状态：待审核 / 已录取 / 未通过

注意事项：

- 一名学生同时只能有一个「待审核」或「已录取」的申请，重复申报会被拒绝
- 已确定课题后不能再申报其它课题
- 课题名额满了会提示「该课题名额已满」

### 2. 开题

被录取后，**我的论文** 会出现论文记录，状态为「待提交开题」。

1. 进入 **开题管理**，填写报告正文（研究背景、内容、技术路线、进度安排）
2. 上传附件（可选，支持 PDF / Word / 压缩包 / 图片）
3. 点击 **提交开题报告**

提交后状态变为「开题待审核」。若被导师退回，状态回到「待提交开题」，页面会出现审核意见，修改后可重新提交。

### 3. 中期

开题通过后，进入 **中期检查**：

1. 拖动滑块填写完成进度百分比
2. 填写报告正文（已完成工作、存在问题、后续计划）
3. 上传附件，提交

若被退回，同样可以修改后重交。

### 4. 定稿

中期通过后，进入 **论文定稿**：

1. 上传定稿文件（PDF / Word / 压缩包）
2. 填写提交说明（选填）
3. 点击 **提交定稿**

系统会自动记录版本号，历史版本在页面下方可查、可下载。评阅被退回时也可以重新提交，版本号继续递增。

### 5. 答辩与成绩

- 评阅通过后，管理员会安排答辩组，状态变为「待答辩」
- 答辩完成后可在 **我的论文** 或 **成绩管理** 查看各项成绩与总评
- 归档后流程结束

**我的论文** 页面可以一次看到：当前阶段、流程进度条、各阶段材料、评阅记录、答辩信息、操作时间轴。

## 二、指导教师

### 1. 出题

进入 **课题管理** → **新建课题**，填写课题名称、类型、来源、届别、可选人数、简介与任务要求。

- 新建后是「草稿」状态，学生看不到
- 确认后点 **发布**，状态变为「开放申报」
- 招满或不想再收人时点 **关闭**
- 已有学生申报的课题不能删除

### 2. 审核选题

进入 **选题管理**，看到的是自己课题收到的申请：

- 点 **录取** → 系统自动为该学生创建论文记录、回填指导教师，该生的其它待审申请自动驳回
- 点 **驳回** → 需要填写意见（也可留空，默认「未通过审核」）

> 名额是并发安全的：同一课题最后一个名额被同时录取时，只有一次会成功。

### 3. 审核开题 / 检查中期

- **开题管理**：列表默认显示自己指导的论文，点 **审核** 选择「通过」或「退回修改」，可同时给开题成绩与意见
- **中期检查**：除了报告列表，还有一个 **超期预警** 页签，列出处于「等待学生提交」且已过截止日期的论文，按超期天数从多到少排序

> 截止日期在「系统管理 → 系统配置」中由管理员设置（`deadline.proposal` / `deadline.midterm` / `deadline.final`），留空表示不预警。

### 4. 查看进度

**论文管理** 可以看到自己指导的全部论文及所处阶段；点 **详情** 进入完整档案（含操作时间轴）。

## 三、评阅教师

### 评阅流程

1. 被指派后，顶栏铃铛会收到通知
2. 进入 **论文评阅** → **待我评阅** 页签
3. 点 **定稿** 打开论文文件（盲审模式下不显示学生信息）
4. 点 **评阅** 填写评阅成绩与评阅意见，提交

### 提交后的自动处理

所有评阅人**全部提交后**，系统自动结算：

| 评阅平均分 | 结果 |
| --- | --- |
| ≥ 60 | 论文推进到「评阅已通过」，进入待答辩 |
| < 60 | 论文退回「定稿已提交」，通知学生修改后重交 |

> 只有成绩或只有意见也可以提交，但两者都为空会被拒绝。成绩需在 0 ~ 100 之间。

被编入答辩组后，**答辩管理 → 答辩成绩** 中也可以为本组学生录入答辩成绩。

## 四、管理员

管理员的职责是保证流程顺畅推进。按时间顺序：

### 阶段 0：系统准备（首次使用）

1. **系统管理 → 字典管理**：确认学院 → 专业 → 班级三级树是否符合本院实际，可增删改
2. **系统管理 → 批量导入**：下载 Excel 模板 → 按说明填写 → 上传导入

   模板里学生的届别、学院、专业、班级**必须与字典中的名称完全一致**，否则整批不导入并返回逐行错误报告
3. 也可以逐个维护：**基础数据 → 学生管理 / 教师管理**

   新建学生时账号即学号，初始密码留空则使用系统默认密码；教师可单独打开「可被指派评阅」开关

4. **系统管理 → 系统配置**：
   - `score.weight.*` 调整总评权重（开题 / 中期 / 评阅 / 答辩）
   - `deadline.*` 设置各阶段截止日期，用于超期预警

### 阶段 1：选题

**选题管理** 可查看全院选题申请。正常情况下由指导教师录取，管理员负责协调异常情况（如教师长期未处理）。

### 阶段 2：指派评阅

学生提交定稿后：

1. 进入 **论文评阅** → **评阅指派** 页签
2. 列表是状态为「定稿已提交」的论文
3. 点 **指派评阅**，选择评阅教师；**留空则由系统自动挑选当前待办最少的教师**
4. 可按需打开盲审开关

首次指派会把论文推进到「评阅中」；同一篇论文可以指派多位评阅人。

### 阶段 3：编排答辩

评阅通过后：

1. **答辩管理 → 答辩组管理** → **新建答辩组**（名称、届别、答辩时间、地点）
2. 点 **详情** → 设置成员（可指定组长、秘书）→ 保存
3. 从「评阅已通过」的学生中选择 → **编入答辩组**，状态变为「待答辩」
4. 学生需要调整时可 **移除**（已录入成绩的不能移除）

### 阶段 4：录入成绩

答辩结束后，在 **答辩管理 → 答辩成绩** 中为每名学生点 **录入**：

- 填答辩成绩
- 答辩结论**留空时按成绩自动判定**：≥ 75 通过、≥ 60 暂缓、否则不通过
- 保存后论文状态变为「答辩完成」，并自动重算总评、通知学生

### 阶段 5：归档

最后一步：**论文管理** → 找到「答辩完成」的论文 → **详情** → 点 **归档**，状态变为「已归档」，流程结束。

### 其他日常操作

| 操作 | 位置 |
| --- | --- |
| 查看全院统计、待办 | 数据看板 |
| 重置某账号密码 | 账号管理 / 学生管理 / 教师管理 |
| 调整评分权重后重算某人总评 | 成绩管理 → 重算 |
| 查看某人完整档案与时间轴 | 论文管理 → 详情 |

## 五、关键规则速查：谁能推进到哪个状态

系统对每次状态变更都校验「当前状态是否允许」与「当前角色是否有权」，不满足会返回可读原因。

| 目标状态 | 允许操作的角色 | 触发入口 |
| --- | --- | --- |
| 待提交开题 | 指导教师、管理员 | 开题审核时退回 |
| 开题待审核 | 学生 | 提交开题报告 |
| 开题已通过 | 指导教师、管理员 | 开题审核通过 |
| 中期待检查 | 学生 | 提交中期报告 |
| 中期已通过 | 指导教师、管理员 | 中期检查通过 |
| 定稿已提交 | 学生、评阅教师、管理员 | 提交定稿 / 评阅退回 |
| 评阅中 | 管理员 | 指派评阅 |
| 评阅已通过 | 管理员、评阅教师 | 评阅全部提交且平均分 ≥ 60 |
| 待答辩 | 管理员、评阅教师 | 编入答辩组 |
| 答辩完成 | 管理员、评阅教师 | 录入答辩成绩 |
| 已归档 | 管理员 | 手动归档 |

> 也就是说：**学生只能主动提交材料，导师负责审核，管理员负责编排与兜底**。任何角色都不能跳步推进。

## 六、常见操作提示

**材料传错了怎么办**
重新提交即可，开题与中期会保留最新一次，定稿按版本号累加。

**附件删不掉**
只能删除自己上传的附件；已被引用到材料中的附件建议通过重新提交来替换。

**看不到某个菜单**
菜单按角色裁剪。例如学生看不到「论文管理」，评阅教师看不到「选题管理」，这是设计如此。

**页面提示「无权限访问该资源」**
说明当前角色没有该操作权限（接口返回 403）。数据级权限由后端裁定，前端隐藏按钮只是体验优化。

**登录后提示「登录状态已失效」**
Token 有效期为 12 小时且不滑动续期，长时间挂机后需要重新登录。
